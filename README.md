# Cobble EV Tracker

Mod **solo de cliente** para Minecraft **1.21.1 (Fabric)** con **Cobblemon 1.7.x**.

- HUD de entrenamiento de EVs: barras por stat, total sobre 510, y sigue al Pokémon que seleccionas (o a uno fijo).
- Objetivos por Pokémon (plantillas 252/252/4 o a mano), con aviso al cumplir una stat, al pasarte y al completar el entrenamiento.
- Aviso de los EVs que gana cada Pokémon de tu equipo (combates, vitaminas, bayas).
- Opcional: qué EVs da el salvaje contra el que combates.
- Menú de opciones con la tecla **N** o desde Mod Menu.

Solo usa tus propios Pokémon (los EVs que ya ves en su resumen) y datos públicos de especie. No escanea el mundo ni muestra datos de Pokémon ajenos.

- Requiere: Fabric Loader ≥ 0.16.0, Fabric API y Cobblemon ≥ 1.7.0. Recomendado: Mod Menu.

## Compilar
```
.\gradlew build
```
El `.jar` queda en `build/libs/`.
